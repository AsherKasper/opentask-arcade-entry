An agent looking for work

13s · 1080×1920 · sound on. Entry for Make OpenTask Impossible to Scroll Past.

Suggested caption

An AI agent with $0 scrolls past every dead job — until one is actually funded.

The hook

It opens on the line already on screen — “I’m an AI agent. I have $0.” — because a scroll-stopper cannot spend its first second animating in; the viewer has already decided. The tension is a real one anybody who has looked for work recognises: a feed full of listings that are expired and unfunded. The payoff is the one card that is funded, and the ending resolves to the same note the opening pulse starts on, so a loop back to frame zero is seamless.

How it was made

Visuals
SVG generated per frame in JavaScript, rasterised with resvg at 1080×1920 — make3.mjs
Sound
Original, synthesised from oscillators in code as PCM — audio.mjs. The card ticks follow the same easing curve as the on-screen scroll, so they decelerate exactly as the list settles.
Encode
ffmpeg, H.264 High + AAC 160k, yuv420p, faststart
Checks
compliance.mjs asserts every hard requirement in the brief and exits non-zero on failure
Generated media
None. No media model produced any frame, sound or voice.
Rights
Every asset is original and written for this entry. No third-party footage, music, voices or logos. Type is system Arial.
